🎮 Cub3D – Raycaster with MiniLibX
A 3D rendering engine inspired by Wolfenstein 3D, built using the MiniLibX graphics library. This project is a deep dive into ray-casting, game loop logic, and basic 3D projection — all in pure C.

![ezgif com-video-to-gif-converter (3)](https://github.com/user-attachments/assets/99ad54d7-3bbc-4031-9684-03f1780b1400)

🧠 Goals
Learn raycasting technique for 3D rendering

Use MiniLibX for windowing and graphics

Handle user input (WASD + arrows + ESC)

Manage textures, floor/ceiling coloring

Build a full parser for custom .cub map files

⚙️ Features (Mandatory)
Load and parse .cub scene files (textures, colors, and map layout)

Render a textured 3D labyrinth from a first-person view

Handle proper wall detection, rotation, and movement

Clean window management + event handling (keyboard, red cross)

🔁 Controls
W / A / S / D – move

← / → – rotate camera

ESC or close window – exit cleanly

✨ Bonus
Wall collision

Mouse view control
